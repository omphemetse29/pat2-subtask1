# C++ Morse Code Translation Program

## 1. Introduction

This project is a C++ application that translates English messages into Morse code.
The program allows users to enter a short message and converts each English letter
into its corresponding Morse code representation.

The program supports uppercase and lowercase letters and ignores numbers,
spaces, and special characters.

## 2. What Is Morse Code?

Morse code is a communication system that represents letters and numbers using
sequences of dots (.) and dashes (-).

It was developed in the 1830s and became widely used for sending messages over
telegraph systems. Morse code is also used in radio communication and emergency
signalling.

- A dot (.) represents a short signal.
- A dash (-) represents a long signal.
- Spaces separate individual letters and words.

## 3. Objectives

The objectives of this project are to:

- Develop a C++ program that translates English letters into Morse code.
- Practise using variables, functions, loops, and conditional statements.
- Convert lowercase letters to uppercase.
- Display Morse code for each letter separately.
- Display the complete Morse code message.
- Practise version control using Git and GitHub.

## 4. Features

The program provides the following features:

- Accepts a message entered by the user.
- Converts lowercase letters into uppercase.
- Translates letters A to Z into Morse code.
- Displays each letter and its Morse code on a separate line.
- Displays the complete Morse code message.
- Separates individual letters with three spaces.
- Ignores numbers, spaces, and special characters.
